# Employee Management System

A responsive Employee Management System developed using HTML, CSS,
and JavaScript for Task 4 of the Auspify Technologies Software
Development Internship.

## Features

- Add employee records
- Edit employee details
- Delete employee records
- Search employees
- Filter by department
- Filter by employment status
- Dashboard statistics
- Department-wise employee overview
- Form validation
- Prevent duplicate email addresses
- Save records using browser Local Storage
- Export employee records to CSV
- Responsive design for desktop and mobile

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser Local Storage

## How to Run

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` using the Live Server extension.
4. Click Add Employee to create an employee record.
5. Test the search, filters, edit, delete, and CSV export features.
